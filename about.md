# Structure Tools

Editor tools that build level structure for you.

## Stage 1: Fill Pillars

1. Select the platform blocks (1x1 blocks or 45° slopes).
2. Press **Pillars** (right side of the editor).
3. A column of blocks is placed under each selected block, down to the ground or until it hits another object.

Use **Pick ID** (select exactly one block first) to choose which block is used for filling. Ctrl+Z undoes a whole fill in one step.
