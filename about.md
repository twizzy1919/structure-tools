# Structure Tools

Editor tools that build level structure for you.

## Menu

Open the **Edit** tab and press the small **Auto** button (first empty slot on the bottom row). The menu has:

- **Style**: Pillars for now.
- **Direction**: Auto reads the lines on each block. Down or Up forces one direction.
- **Max height**: how many blocks a pillar can have.
- **Structure**: runs it. With nothing selected the whole level is scanned, otherwise only the selection.
- **Show ID**: shows the object ID of the selected blocks.

**Pillars.** Wide platforms get line blocks on the outer sides and a plain filler in the middle. 45° and 2x1 slopes are supported. Lines are hidden where a pillar touches another block or slope. Ctrl+Z undoes a whole run.
